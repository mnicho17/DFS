## Scoring and decision boundaries

Primary endpoint: factor-1 empirical CRPS minus inherited-reference CRPS. Compute per-defense CRPS as mean(abs(X-y)) minus sum((2*i-n-1)*sorted_X[i]) / n^2 with i=1..n. Average both DSTs within game, then equally weight games. Negative differences favor the candidate. DSTs and thousands of draws are not independent game replications. No fee/payout, ROI, lineup-selection or field-simulation claim is part of this endpoint.

Report every factor and both references with bias, analytic/sample SD, p10/p90/p95, 80-percent interval score and coverage, floor probability, P(DST>=8) and its Brier score, per-seed values and per-game differences. Fixed empirical quantile index is floor((n-1)*p). Interval score is hi-lo + 10*max(lo-y,0) + 10*max(y-hi,0), with inclusive interval coverage. Include negative/zero/strict-positive actual counts and corresponding supported subgroup summaries; no denominator means unavailable. Report leave-one-game-out primary differences and game-level better/equal/worse counts, not a significance or causality claim. Do not add a new joint-event acceptance gate to this marginal study.

Require at least ten qualified games and twenty DST actuals, both DSTs in each included game, before even describing this as the minimum-supported prospective comparison. This is an explicit descriptive support gate, not a power calculation or production acceptance threshold. At window end, report insufficient support if it is not met; any extension is a separate declaration, not an opportunistic continuation. No in-window tuning or automatic winner/default selection. Even a favorable primary score requires review of means, calibration/tails, support, sensitivity and a separate dependence/production proposal.
