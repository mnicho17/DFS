# DFS Optimizer v1.18.0

## Joint Contest SIM

- The selected NFL Classic portfolio is now evaluated as one set in the same exact-payout contest.
- Your own entries occupy ranks together, compete for the same prizes, and share ties with one another and sampled opponents.
- Portfolio Insights and copied build reports show total cost, expected payout and profit, profit and double-up chances, any top-10 probability, payout percentiles, and a 95% ROI range.
- A pre-build warning catches a contest profile whose planned entry count differs from the requested lineup count.

![Joint selected-portfolio economics and uncertainty](../images/contest-portfolio-outlook.png)

## Broader scenario coverage

- Each scenario uses an explicit balanced, shootout, defensive, or blowout game script influenced by available totals and spreads.
- Player scoring ranges now account for position, depth order, role, usage, ownership, and injury uncertainty.
- Guarded rare ceiling outcomes retain the long tails that matter in large-field tournaments.
- Candidate grading and joint validation rotate across three sampled opponent fields.
- Adaptive stopping is allowed only after the estimated ROI is both stable and sufficiently precise; volatile top-heavy contests continue to the scenario limit.

![NFL SIM results with portfolio-adjusted ROI](../images/nfl-sim-results.png)

## Compute and learning

- Deep mode reserves part of its five-minute budget for the final joint-contest pass when a payout profile is attached.
- Export history marks portfolio-adjusted estimates and retains the earlier standalone ROI for future validation.
- Existing preset-only NFL SIM, other sports, Showdown, portfolio constraints, Entry Safety, and DraftKings export formats are unchanged.

Simulation results depend on the loaded projections, ownership, live context, contest profile, and model assumptions. They are estimates, not guaranteed returns.
