# DFS Optimizer v1.15.0

## Entry Safety

- Export now checks the exact saved portfolio before opening the file-save dialog.
- Hard blockers include incomplete or position-invalid rosters, missing DraftKings IDs, repeated players, salary-cap violations, duplicate entries, unavailable players, and current portfolio-rule violations.
- Questionable players, stale or incomplete slate data, and unusually low salary use remain explicit review items that can be acknowledged.
- The report can be copied and never changes a lineup or setting.

## Saved build recipes

- Current contest and strategy settings can be saved under a reusable name from **Settings**.
- Recipes can be inspected, applied, or deleted without adding controls to the main workspace.
- Sport, contest type, lineup count, salary, ownership, build style, NFL SIM, preset, compute depth, uniqueness, and concentration settings are retained.
- Player locks, fades, exposure limits, and groups are deliberately excluded so stale slate decisions cannot leak into a new slate.

## Documentation

- The user guide includes new visual references for Entry Safety and saved build recipes.
- The five-minute workflow now includes the final export gate and recipe reuse.
