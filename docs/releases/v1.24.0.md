# DFS Optimizer v1.24.0 - Core Plans and Captain safeguards

Core Plays now lets you choose players and apply portfolio targets to the current loaded NFL pool. Classic counts regular appearances; Showdown tracks FLEX and Captain separately. Targets guide generation and selection without locking players or weakening hard rules. Build reports show achieved counts and missed targets.

New Showdown candidates exclude a QB Captain paired with a known opposing defense across build styles. Kicker Captain exposure has an aggregate default cap of 5% of requested entries, rounded down with a minimum of one. Explicit kicker Captain locks and retained entries take precedence; reports disclose exceptions. The cap also applies during feasibility repair and automatic-cap recovery.

The bottom Showdown output controls filter by Captain. Mean pts sorts the complete SIM result set in descending order before pagination. Saving and unsaving filtered rows still uses the original lineup identity, and filtering preserves existing saved entries.

The existing branch's bounded diversity-first feasibility pass remains in place and respects the new Captain limits as well as current-main recovery constraints. It reserves at most three seconds within the existing feasibility budget and keeps CBC repair as the fallback. Reports identify the method used.

This release is built on current reviewed main, retaining the already-merged contest objective, compute ledger, historical evidence, portfolio risk, and hindsight workflows. It does not start new work on those features.
