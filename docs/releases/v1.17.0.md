# DFS Optimizer v1.17.0

## Contest-Aware SIM

- Save reusable NFL Classic contest profiles with the real field size, entry fee, intended entry count, and payout tiers.
- Simulated finishes now use the attached contest's prizes instead of the generic return proxy.
- Tied scores and duplicated lineups share all prizes covered by their finishing range.
- Classic results show expected ROI beside SIM Edge; lineup details add expected payout and profit.
- Portfolio Insights and copied build reports summarize the selected portfolio's expected contest ROI.

![Contest-Aware SIM profile with exact contest economics](../images/contest-aware-sim.png)

## Learning and guardrails

- Export history retains the contest-specific estimates so imported results can compare predicted ROI with actual ROI over time.
- Profiles are validated for field size, entry fee, entry count, payout ranges, overlaps, and paid places.
- Existing presets remain the opponent-construction model, and **Use Preset Only** preserves the previous workflow when no payout table is attached.

Contest projections remain estimates based on the loaded player projections, ownership, correlations, and representative opponent field. They do not guarantee a return.
