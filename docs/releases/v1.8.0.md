# DFS Optimizer v1.8.0

## Slate Readiness

- Added a one-click, report-only preflight with a 0-100 readiness score.
- Separated findings into Pass, Review, and Block with a specific next step for every gap.
- Added checks for roster viability, projections, ownership, locked unavailable players, NFL news freshness, role uncertainty, backups, and optional Vegas context.
- Added a post-generation review of complete rosters, salary use, and NFL contest-preset fit.
- Added a copyable readiness report without changing projections, locks, fades, or lineups.

## Clearer NFL simulation decisions

- Added contest-preset fit for salary use, QB stacks, bring-backs, FLEX mix, and ownership coverage.
- Added a **Why this SIM Edge** breakdown with component percentile, direction, and weight.
- Kept field-learning guardrails unchanged; limited early samples remain report-only.

## Generation feedback

- Labeled candidate generation, field simulation, and portfolio selection as separate progress phases.
- Reset prior generated-lineup analysis when a new salary file is loaded so readiness cannot compare a new slate with an old portfolio.

## Documentation

- Updated the user guide, quick start, troubleshooting, and repository overview for Slate Readiness and the expanded SIM explanations.
