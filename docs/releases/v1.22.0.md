# DFS Optimizer v1.22.0

## Shareable Results & Learning reports

Results & Learning now offers **Export Review Report**. Choose filters, preview the captured evidence, and save a ZIP containing `summary.md` and `evidence.json`. Detailed lineups and player explanations are optional. Default summaries omit player/account/entry/contest names and source paths. Review your optional observation before sharing it.

The report distinguishes recorded performance, build settings, data quality and issues. Missing winnings remain unknown rather than zero; monetary comparisons use the same eligible entries. Historical ownership, forecast and matching limitations remain visible. Exporting does not change history, retrain projections, or change strategy.

Existing version-1 build archives and snapshots can explain saved Captain locks, exposure limits, quarterback eligibility and selection settings. The report distinguishes archived output matches from compatible snapshot comparisons. A name-roster match is not proof of the originating build, submission or player-ID identity. Saved code fingerprints are preserved; unavailable historical Git revisions remain unavailable.

Use **Choose history folder** to read history from another checkout without moving it. Input scans and optional details are bounded, with truncation and unavailable evidence disclosed. Cancelling or closing a capture preserves source data; report publication validates the ZIP before replacing the destination.
