# DFS Optimizer v1.8.1

## Lineup Space dashboard

- Added a compact view of the eligible build pool, structural lineup possibilities, and requested lineup count.
- Recalculates immediately after fades, locks, inactive-player removal, and lineup-tab changes.
- Uses the same starter/rotation pool as NFL Classic SIM generation so omitted deep backups visibly shrink the space.
- Clearly distinguishes exact NFL roster-shape counts from upper bounds and explains that salary, correlation, exposure, and uniqueness rules narrow the pool further.

## Clearer generation diagnostics

- Shows Generate, SIM, and Select as live stages in the compact dashboard.
- Records generation, simulation, selection, and total elapsed time for the last build.
- Reports candidate count versus selected lineup count in the dashboard tooltip.

## Readiness player drill-down

- Added **Show Players** and double-click actions for readiness findings involving missing projections, missing ownership, locked unavailable players, questionable players, and deep backups.
- Added a visual-only player-table filter with a clear action; filtering never changes lineup eligibility by itself.

## Documentation and validation

- Added current screenshots for the Lineup Space dashboard and Slate Readiness player drill-down.
- Updated the user guide, quick start, repository overview, and release process.
- Passed the complete 76-test suite, including 150-lineup Classic and Showdown performance checks.
