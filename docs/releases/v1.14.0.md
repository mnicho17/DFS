# DFS Optimizer v1.14.0

## A quieter workspace

- The normal workflow now fits in one compact command bar: load the slate, run the game-day checks, choose the sport, and generate.
- Detailed Build Strategy, Portfolio Rules, and Data and Learning controls are folded away at startup and remain available through **Settings > Show Build Controls**.
- A small recipe summary keeps the active style, salary approach, SIM depth, and contest preset visible while the detailed controls are closed.
- The saved-portfolio panel stays out of the way until a lineup is saved. It can be hidden or restored manually from Settings.
- Duplicate Generate buttons were removed so the blue command-bar action is the single obvious way to start a build.

## Better use of table space

- Classic and Showdown output columns expand across the available window instead of leaving a large empty gutter.
- The player table continues to use sport-specific defaults, keeping MLB-only fields away from football and basketball slates.
- The selected-player inspector is wider and uses shorter action labels so exposure and team controls no longer clip.
- Settings-menu labels now use safe plain text, correcting the Portfolio Insights artifact and the visual underscore caused by ampersand mnemonics.

## More useful Deep Build polish

- After normal portfolio improvement, Deep Build can spend its remaining budget replacing high-duplication lineups while retaining the combined SIM Edge and return signal.
- Every replacement still rechecks uniqueness, player exposure, groups, team limits, and game limits.
- The search stops at the time limit or a constrained local optimum rather than running solely to consume five minutes.
- Build reports now separate general swaps from duplication-polish swaps and report search passes, elapsed polish time, stop reason, and unused budget.

## Validation and documentation

- The complete automated suite passes 101 tests.
- The user guide explains the folded controls and saved-portfolio behavior.
- Main workspace, Deep Build, lineup-space, Portfolio Rules, and NFL SIM result screenshots were refreshed from the real application UI.

The simplified shell does not remove optimizer functionality. Advanced controls, diagnostics, local learning, portfolio repair, and export behavior remain available when needed.
