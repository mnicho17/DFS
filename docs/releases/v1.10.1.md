# DFS Optimizer v1.10.1

## 20-Max completion fix

- Fixed an app-closing error that could occur after an NFL Classic 20-Max build completed when its saved real-field reference did not contain a duplication measurement.
- Missing historical duplication values now display as **n/a** in the completion comparison.
- Lineup generation, simulation, selection, scoring, and preset behavior are unchanged by this fix.

## Validation

The fix was reproduced and verified with the 715-player NFL Week 1 validation slate, a five-lineup 20-Max build, and 750 SIM scenarios through the normal background-build and desktop completion path. The build completed, displayed all five lineups, and safely reported the unavailable real-field value as **n/a**.

The complete 86-test desktop suite passes, including a new regression test for incomplete real-field comparison data.
