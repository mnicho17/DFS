# DFS Optimizer v1.10.0

## Scenario-driven NFL candidate generation

- NFL SIM Edge now actively builds candidates from correlated outcome scenarios instead of only grading lineups created from base projections.
- The scenario source rotates through Ceiling, Balanced, Leverage, and Low-Dup constructions.
- Scenario-built lineups remain complete, unique, near the salary cap, and inside the same NFL correlation safety rails as the rest of the candidate bank.
- Candidate creation and contest evaluation use separate seeded scenario streams so the final portfolio is not selected against the same outcomes that created it.
- Portfolio selection now applies a soft quality guardrail below the B-grade boundary, so a novel game script must provide meaningful marginal value before it can displace a stronger lineup.

## Balanced candidate budget

- A normal unrestricted 150-lineup SIM build keeps a 500-candidate budget: 300 optimizer, 60 field-shaped, and 140 scenario-built candidates.
- Locks and hard portfolio rules keep their wider optimizer-only path so every candidate honors those requirements by construction.
- Build reports now show all three candidate sources separately.

## Validation

Using the 715-player NFL validation slate, all 500 candidate slots were filled with unique lineups. Scenario-built candidates earned 33 of the final 150 portfolio positions. The selected portfolio contained 55 A, 89 B, and 6 C slate-relative SIM grades in the development benchmark, compared with the earlier B/C-heavy result. Total development-runtime build time was approximately 23 seconds with 750 evaluation scenarios.

The complete 85-test desktop suite passes, including the 150-lineup performance checks, deterministic scenario generation, selection-quality guardrails, and locked-player safeguards.

SIM grades remain slate-relative decision aids rather than outcome guarantees. Review news, exposure, construction, leverage, duplication risk, and portfolio coverage before entry.
