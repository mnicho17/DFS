# DFS Optimizer v1.7.0 (development draft)

Version 1.7.0 begins connecting NFL contest simulation to measured opponent-field behavior while keeping small or partial samples safely out of automatic tuning.

## New in this version

- NFL Classic includes **Single Entry**, **3-Max**, **20-Max**, and **150-Max** contest presets.
- Each preset shapes the representative field's size, salary floor, ownership emphasis, QB stacks, bring-backs, and FLEX mix.
- Results & Learning recognizes complete DraftKings standings separately from personal entry-history files.
- Large fields are summarized as a stream, keeping the local learning database compact instead of storing millions of redundant opponent-player rows.
- DraftKings files without explicit sport or contest-name columns can infer NFL from roster slots and 150-Max from entry labels such as `(92/150)`.
- Complete fields report actual ownership, exact roster duplication, top-one-percent duplication, salary use, QB stacks, bring-backs, and FLEX position patterns.
- Complete fields also profile total lineup ownership, low-owned and high-owned player counts, and ownership bands for the full field versus the top one percent.
- Results & Learning imports large standings in the background with visible progress and safe cancellation.
- **Attach Matching Salaries** adds salary, QB-stack, bring-back, and FLEX detail when a standings export omits player metadata. A 70% slate-match check prevents accidental cross-slate attachment.
- The learning report compares the latest NFL SIM representative field with the measured real field for the same preset.

## Learning guardrails

- A file must contain at least 25 entries and roughly 95% of the advertised field before it is treated as complete standings.
- A contest remains report-only unless its contest name or CSV filename identifies **Single Entry**, **3-Max**, **20-Max**, or **150-Max**.
- A learned preset blend requires at least three complete fields, 1,000 field entries, and 70% player metadata coverage.
- Eligible learning is blended conservatively with the baseline preset; it does not replace the baseline outright. The winning-ownership profile has only a small influence on candidate scoring.

## Testing focus before release

- Import one real complete DraftKings NFL Classic standings file.
- Confirm the detected preset, field-entry count, ownership coverage, winning ownership bands, duplication, salary, stack, and FLEX summaries.
- Cancel a large import and confirm no partial field is saved, then import it fully and attach the matching salary file.
- Generate the same slate under multiple contest presets and confirm the reported representative field changes.
- Export a SIM build and confirm **Real Field vs latest NFL SIM** reports the measured differences.
- Confirm ordinary personal contest-history imports continue to update results without becoming opponent-field training data.
