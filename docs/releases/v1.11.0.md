# DFS Optimizer v1.11.0

## Portfolio Insights

- A new Portfolio Insights report explains the generated or saved lineup set without changing it.
- The overview summarizes grades, salary bands, ownership shape, QB stacks, bring-backs, FLEX usage, leverage, duplication risk, preset fit, concentration, and scenario coverage.
- NFL SIM lineups retain whether they came from the optimizer, field-shaped generation, or a correlated scenario build.
- Scenario-built selections identify their Ceiling, Balanced, Leverage, or Low-Dup archetype.
- A sortable lineup-detail table exposes the major signals for each lineup.
- Automatic review flags call attention to weak grade mixes, high duplication, unusual unused salary, unstacked NFL lineups, and concentrated player cores.

## Build comparison and recovery

- Build History can compare two selected runs side by side using candidate counts, phase timing, contest preset, SIM quality, duplication risk, scenario coverage, and selected source mix.
- Unexpected interface exceptions are contained by an application-level recovery message with copyable technical details, allowing valid visible lineups to remain available.

## Performance

- High-volume Showdown builds cache static player and correlation scores during generation, preserving the same rules while substantially reducing repeated work.

## Validation

The desktop suite includes regression coverage for candidate-source preservation, incomplete optional SIM metrics, Portfolio Insights calculations and UI, privacy-safe build comparison, application-level exception recovery, and high-volume Showdown performance.
