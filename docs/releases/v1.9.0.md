# DFS Optimizer v1.9.0

## Shareable build reports

- Added **Settings > Copy Last Build Report** for a one-click performance snapshot after generation.
- Reports include the eligible and omitted pool, structural lineup possibilities, requested and generated candidates, selected lineups, strategy settings, portfolio rules, preset fit, and generalized warnings.
- Breaks elapsed time into Generate, SIM, and Select phases and identifies the slowest phase automatically.

## Local build history

- Added **Settings > Build History…** to compare and copy the 25 most recent completed or cancelled lineup builds.
- Added a clear-history action that does not affect exported lineups, imported results, or other learning data.
- Stores aggregate settings and counts only—never player names, lineup contents, salary-file paths, or API keys.

## Documentation and validation

- Added a Build History reference image and updated the user guide, quick start, troubleshooting guide, and repository overview.
- Added automated coverage for report formatting, privacy filtering, local history retention, clipboard actions, and corrupt-history recovery.
- Passed the complete 80-test suite, including 150-lineup Classic and Showdown performance checks.
