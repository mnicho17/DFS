# DFS Optimizer v1.6.0

Version 1.6.0 makes NFL Classic lineup quality easier to judge and makes the main workspace less crowded without removing controls.

## Highlights

- NFL SIM Edge now compares every candidate lineup with the same representative field across correlated game scenarios.
- Classic results show SIM Edge and top-one-percent rate directly, with top-five-percent rate, cash rate, bust rate, simulated ceiling, return index, leverage, duplication risk, scenario count, and field size in the detail tooltip.
- The 150-lineup selector rewards coverage of different winning scenarios instead of simply taking near-duplicate high projections.
- The main controls are organized into **Build Strategy** and **Portfolio Rules**, while saved-lineup and export functions remain available.
- Sport-aware tables hide irrelevant analysis columns, such as baseball-only details on football slates.
- Generation progress, cancellation, live NFL status, Vegas handling, and Results & Learning remain intact.

## Download

Download `DFS-Optimizer.exe` and, if desired, verify it with `DFS-Optimizer.exe.sha256`. The release also includes `DFS-Optimizer-User-Guide.pdf`.

## Important notes

- The Windows executable is not code-signed, so Windows may show an unknown-publisher warning.
- SIM outputs are estimates based on the loaded projections, ownership, correlations, and field assumptions. They are not guarantees.
- Run **Game-Day Check** close to lock and review every exported entry before submitting it.
