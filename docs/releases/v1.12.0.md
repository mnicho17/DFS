# DFS Optimizer v1.12.0

## Actionable Portfolio Insights

- Portfolio Insights now identifies the exact lineup rows behind each review signal.
- Filter all flagged lineups or focus on C/D grades, high duplication, more than $2,000 unused salary, no NFL QB stack, or a concentrated player core.
- Select flagged rows in one click, or choose individual rows manually.
- Remove selected rows from the current generated or saved set after confirmation.
- Replace selected rows while keeping every unselected lineup fixed. Only the open slots are generated again with the current slate, strategy, and portfolio rules.

## Player exposure drill-down

- A new Player exposure tab shows every player's lineup count and portfolio percentage.
- Each exposure row lists the exact lineup numbers containing that player.
- Jump directly from a player to those lineup rows before deciding what to remove or replace.

## Repair safety and performance

- Retained lineups participate in uniqueness, player exposure, team, game, group, and scenario-coverage calculations during replacement.
- Duplicate candidates are excluded from the retained portfolio.
- Classic generation can treat retained lineup signatures as already used, allowing it to search directly for the requested replacements instead of rebuilding the entire portfolio.
- Saved-set repair refreshes saved rows and generated checkboxes together; cancelled or infeasible repair never silently removes retained lineups.

## Documentation and validation

- The user guide, quick start, troubleshooting guide, and Portfolio Insights screenshots now cover filtering, removal, partial replacement, and player exposure.
- Regression coverage verifies review flags, player-to-lineup exposure mapping, retained-lineup selection, partial Classic repair, and the three-tab Portfolio Insights interface.
