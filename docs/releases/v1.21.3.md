# DFS Optimizer v1.21.3

## Saved repair safety (AR-01)

- Cancelling a saved Classic or Showdown repair preserves the current saved entries and their reports.
- Incomplete, obsolete, or mismatched proposals cannot replace the saved portfolio. Current news and newer saved edits remain intact.
- A complete valid repair applies once, including when a completion callback is delivered again.
- Build History distinguishes computation from whether a saved repair was applied.
- Closing during a build requests cooperative cancellation and waits for worker cleanup.
- Ordinary generated-only partial results and successful repair ordering remain supported.

No strategy, ownership, selection, settlement, or payout formulas changed. PR #37 is not included.

## Verification and limits

The unchanged baseline passed 145 tests. Four real-worker cancellation/apply-once acceptance checks failed on that baseline and passed on AR-01. The implementation passed 164 tests locally and in Windows PR CI, including 19 focused AR-01 methods with format and lifecycle subtests. Automated GUI coverage uses offscreen Qt and isolated settings/data. The documentation image uses synthetic data and is not additional worker evidence. Visible-desktop and packaged-executable runtime smoke tests have not been independently recorded by the agent.
