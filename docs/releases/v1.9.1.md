# DFS Optimizer v1.9.1

## Faster NFL Classic generation

- Strategic, Balanced, Contrarian, and Chalk builds now use the compact NFL starter/rotation pool even when NFL SIM Edge is off.
- Deep backups and unavailable players no longer consume generation time in normal NFL Classic builds.
- Manual locks, minimum player exposures, and required player groups remain eligible, so intentional choices are not removed by the faster pool.
- Randomized with SIM Edge off remains the deliberate broad-pool option when deep backups are wanted.

On the 715-player validation slate, an unrestricted 150-lineup Strategic build improved from 26.41 seconds to 5.69 seconds while still returning all 150 lineups.

## Clearer candidate reporting

- Build reports now call the planned candidate count a budget instead of a target.
- NFL SIM Edge reports separate optimizer candidates from additional field-shaped candidates.
- A build that generates 493 unique candidates from 400 optimizer and 100 field-shaped attempts is now shown as 493 of a 500-candidate budget instead of appearing to exceed a 400-candidate target.

## Documentation and validation

- Updated the user guide, quick start, troubleshooting guide, repository overview, Lineup Space image, and Build History image.
- Added automated coverage for role-pool policy, explicit-player preservation, SIM candidate budgets, and the SIM-off lineup worker path.
- Passed the complete 82-test suite, including 150-lineup Classic and Showdown performance checks.
